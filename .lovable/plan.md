# Farmer Partnership page refinement

## Scope
Redesign only the Farmer Partnership page. Preserve the existing header, footer, navigation, typography and colour system.

## Page changes
- Replace the opening with the supplied headline, supporting copy, “Pilot underway” label, and links to the interest form and partnership model.
- Explain Afrifama’s and the farmer’s responsibilities in balanced columns, with conditional support described as “may provide.”
- Add farm-readiness criteria and six clear readiness gates, stating that every critical gate must pass before selection.
- Replace the short process with the supplied eight-stage responsive farmer journey.
- Add concise post-placement support areas without implying emergency veterinary coverage.
- Simplify recoverable-input language and distinguish what it is from what it is not.
- Add the commercial-risk and farmer-data privacy statements as calm supporting notes.
- Expand the page FAQ to the twelve requested questions, keeping egg-purchase and independent-selling answers conditional on each production-cycle agreement.
- Add a dedicated expression-of-interest form with only the requested fields, consent, browser validation and a clear non-guarantee notice. Keep submission as an honest front-end prototype because enquiry storage/delivery was not requested.
- Finish with the supplied CTA linking to the form and FAQs.

## Content and design
- Keep all reusable partnership wording, lists and FAQs in the central site content file.
- Use the existing farmer-training photograph and established Afrifama visual tokens.
- Favour compact editorial sections, fine dividers, checklists and a clean timeline over oversized cards or excessive whitespace.
- Include no programme figures, testimonials, guaranteed outcomes, repayment formulas or sensitive-data fields.

## Verification
- Check the page at desktop and mobile sizes, including form controls, anchor links and FAQ interactions.
- Confirm metadata, social metadata, accessibility basics and a clean preview build.
