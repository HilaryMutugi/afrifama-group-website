# Afrifama Feeds Page Refresh

## Scope
Redesign only the Feeds page. Preserve the existing header, footer, navigation, colour system, typography and global design language. No other page content or layout will change.

## Page experience
- Build an image-led opening around “Nutrition built for every stage of the flock,” with the supplied buttons and existing feed/raw-material photography. Keep packaging unbranded and make no unsupported production or laboratory claims.
- Add a simple interactive stage selector: Start → Grow → Prepare → Produce. It will remain easy to tap and read on a phone.
- Present all six requested products in a clear commercial range. Every product will show its production stage, nutritional purpose, suitable flock type and a product-information enquiry action.
- Explain how genetics, age, body weight, intake, water, housing, health, ingredient consistency and farm discipline affect feed decisions through a restrained technical relationship diagram.
- Show the five-step feed-development process, followed by a professional quality-discipline section covering supplier assessment through finished-feed review.
- Add farmer-support areas and clearly label feeding guides, record sheets, technical notes and FAQs as future resources rather than available downloads.
- Add distinct pathways for farmers, partner farmers, dealers, commercial farms, technical partners and raw-material suppliers.
- Close with the requested production-system message and buttons for flock and distributor enquiries.

## Content integrity
- Move the six-product range and all reusable Feeds wording into the central content file so verified specifications can be added later in one place.
- Do not add nutrient percentages, feeding rates, prices, bag sizes, certifications, laboratory approvals, endorsements or performance claims.
- Keep product enquiries routed through the existing contact page; no purchasing or enquiry backend will be added.

## Technical details
- Reuse the current feed-material image and existing design tokens/components; no competitor media or copied layouts.
- Keep the existing FAQ structured data, update page metadata for the new positioning, and include the required social metadata.
- Verify the page at desktop and mobile sizes, test the stage selector and links, and confirm a clean preview build.
